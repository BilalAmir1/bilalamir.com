🔗 **[View Live Demo Here](https://bilalamir.com)**

## ✨ Features

- **Server-Side Rendered (SSR) & Highly Optimized:** Built with the Next.js App Router for maximum Core Web Vitals performance.
- **Interactive Fluid UI:** Complex, performant layout animations and scroll effects powered by Framer Motion (`LazyMotion` implemented for optimal bundle size).
- **Decoupled Architecture Showcase:** Dedicated components explaining Headless CMS (Sitecore/Strapi) integration methodologies.
- **Serverless Contact Form:** Fully integrated with EmailJS and React Hook Form for zero-backend, spam-filtered message delivery.
- **Responsive Design:** Mobile-first approach scaling perfectly to ultra-wide desktop monitors using Tailwind CSS.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Forms & Validation:** React Hook Form
- **Email Handling:** EmailJS (@emailjs/browser)
- **Icons:** Lucide React
- **Deployment:** Cloudflare
